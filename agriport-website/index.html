The Challenge

Why Current Solutions Fail Farmers

Indian agriculture faces critical gaps that existing technology fails to address

No Internet, No AI

Internet-dependent crop-AI tools fail in low-connectivity rural farms. Over 60% of Indian farmland lacks reliable mobile data coverage for real-time cloud inference.

60%+ Farms lack reliable connectivity

Vision-Only False Alarms

Camera-only disease detection produces false alarms under poor lighting, water droplets or visually similar nutrient deficiency symptoms, leading to unnecessary pesticide spraying.

30-40% Typical false positive rate (vision-only)

Water Waste & Pump Damage

Manual irrigation scheduling causes water waste, crop stress from over/under-watering, and pump dry-runs when reservoir levels are not monitored — leading to motor burnout.

25-40% Water wasted in flood irrigation

⚙️ Fusion Decision Logic

Hybrid rule-based + ML fusion engine for cross-validation

decision_engine.py 
def evaluate_crop_risk(vision_conf, humidity, temp, soil_moisture):
    # Vision confidence from CNN
    if vision_conf > 0.70:
        # Cross-validate with environmental conditions
        if humidity > 80 and 20 < temp < 35:
            return "HIGH_RISK", "Disease conditions confirmed by sensors"
        else:
            return "MODERATE_RISK", "Visual symptoms detected, environment not typical"
    elif vision_conf > 0.40:
        return "LOW_RISK", "Uncertain — consult agricultural expert"
    else:
        return "HEALTHY", "No disease indicators detected"

def irrigation_decision(soil_moisture, reservoir_level):
    if reservoir_level < 15:  # percentage
        return "PUMP_STOP", "Reservoir critically low — pump disabled"
    if soil_moisture < 30:
        return "IRRIGATE", "Soil dry — irrigation recommended"
    return "HOLD", "Moisture adequate"

📡 Communication Design

Camera

ESP32-CAM with OV2640, 2MP, JPEG compressed

Inference Location

Raspberry Pi 4 — all processing on-device

Image Transfer

Wi-Fi HTTP POST, ~50-100KB per frame

Max Node Distance

~30m (Wi-Fi), extendable with directional antenna

Node Capacity

Up to 4 field nodes per Raspberry Pi

Failure Handling

Local buffer on ESP32, retry on reconnection

⚠️ Risks & Mitigations

💧 Sensor Corrosion

Capacitive soil probes (no exposed metal), IP-rated enclosures

🌅 Poor Lighting

Scheduled capture during daylight, confidence thresholds

🌿 Unseen Crops/Diseases

"Unknown — consult expert" output for low-confidence results

📶 Wireless Range

Tested range documented, directional antenna option

⚡ Unsafe Pump Switching

Contactor + fuse, watchdog timer, fail-safe pump cutoff

🔍 False Positives

Multimodal cross-validation, manual override always available

Validation Methodology

  2. 2 Annotate healthy, disease and pest classes with an agricultural expert
  3. 3 Split data by farm/session — not randomly by similar images
  4. 4 Compare vision-only vs. multimodal results
  5. 5 Test under sunlight, shade and poor lighting conditions
  6. 6 Measure accuracy, latency, power and wireless range
  7. 7 Conduct farmer usability testing with local-language interface
